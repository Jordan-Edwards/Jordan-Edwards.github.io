Tracker Mini groove pages / Native

It looks like it shipped with the device.

Four new pages in the stock theme. Tap the keys under the screen.

Shift latches here. Tap it on, tap it off. Menu steps through the pages. Hold an arrow or a +/- key and it repeats, as on the device.

Or turn the phone sideways.

What this direction is going for

It should look like it shipped with the device. Stock colours, the five stock fonts, the top bar and the label row where they already are.

The groove pages sit in the menu beside Pattern and Song. Opening one never feels like leaving the tracker.

Nothing is decoration. The waveform, the playhead and the meters are the only things that move.

Each screen key owns the two label cells above it. The left cell is a plain press. The right cell is the same key with Shift.

Easy and hard on this screen

Easy: frames, meters, labels, the playhead and its red trail. They are rectangles and one line, and the display chip draws those cheaply.

Hard: waveforms. A frame holds about 8 KB of drawing commands, and 600 waveform columns would use more than half. So the big lane is 192 bars and each small lane is 64, about 3 KB in all. A bitmap uploaded once per loop would be cheaper still.

There is no animation engine. Motion is a few small parts redrawn each frame in whole pixels. At 130 BPM a 4-bar sweep moves about 2 px per frame, which reads as smooth.

What this is

A concept picture drawn in a web page. It is not firmware and none of it has run on the device. Where the keys sit on the case is a guess. The source code does not say. The waveforms and meters are made up.
