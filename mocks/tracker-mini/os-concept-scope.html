Tracker Mini groove-box OS · visual direction

Scope

A tape machine crossed with an oscilloscope. The light tells you what the loop is doing.

Menu steps through the screens. Shift latches here, so one thumb can use it. Arrows pick lanes and slices on Loops, tracks and the next pattern on Perform, source and length on Capture. The plus and minus keys set tempo, or a track level on Perform. Turn the phone sideways to see the screen near its real size.

What this direction is going for

The screen is nearly black. Sound is drawn as light: thin traces, thin type, no panels.

Each loop lane runs the full 800 pixels. The playhead leaves an afterimage, so the trail shows which way it moves. Trail on the left is forward. Trail on the right is reverse. In ping-pong the end walls light up and flash on each bounce.

Teal is playing. Red is recording, the stock red. Amber is anything waiting for the next bar.

The type is the device's own Roboto Mono at its real sizes, plus larger cuts for the big numbers.

Easy and hard on this screen

Easy: lines, points and additive blending are what this display chip does well. The afterimage is nearly free, because the waveform columns are drawn anyway and only their brightness changes, in eight steps.

Tight: a waveform column costs about 8 bytes of an 8,172-byte frame. Loops uses about 400 columns for the big lane and 100 for each small one, near 5.5 KB. Text and markers must fit in the rest, and the soft glow has to stay on the few columns behind the head.

Hard: there is no animation engine, so the lane resize and every fade are redrawn by hand each frame. The playhead moves in whole pixels. The big numbers need a new font slot.

What this is

A concept picture drawn in a web page with made-up audio. It is not firmware and nothing here has run on the device. The key positions are schematic.
